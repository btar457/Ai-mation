# أصوات الحلقة 1 عبر Google AI Studio

## الطريقة

1. افتح aistudio.google.com، ثم **Generate speech** (توليد الكلام)، وسجّل الدخول بحساب Google.
2. اختر **Single-speaker audio** (متحدث واحد). سنولّد كل شخصية وحدها حتى يبقى صوتها ثابتاً في الحلقة كلها.
3. اختر الصوت المقترح لكل شخصية، والصق في خانة **Style instructions** وصف الأسلوب، وفي خانة النص سطورها.
4. اضغط **Run**، ثم نزّل الملف.
5. أرسل لي الملفات الأربعة، وأنا أقصّ كل سطر وأضعه في مشهده.

الكلمات بين قوسين مربعين، مثل `[excited]`، أوامر للمشاعر لا تُقرأ. الوقفة `...` بين السطور تساعدني على قصّ كل سطر وحده، فلا تحذفها.

إن لم يعجبك صوت، فجرّب البديل المكتوب بجانبه. واستمع إلى معاينة الأصوات في AI Studio قبل التوليد.

## 1. رحّال، الصوت: **Puck**، والبديل **Fenrir**

**Style instructions:**
```
Read in clear Modern Standard Arabic as an energetic, playful young boy cartoon character, about 8 years old. Fast, bouncy and enthusiastic, smiling while speaking. Leave a one-second pause between lines.
```

**النص:**
```
[panicked, out of breath] أينَ الواحة؟! كلُّ الكثبانِ متشابهة… لقد ضِعتُ!
...
[excited, jumping] هيّا نتسابق! أوّلُ مَن يصلُ إلى الصخرةِ الحمراءِ هو البطل!
...
[shouting happily, counting] نقفزُ خمسَ قفزات! واحد! اثنان! ثلاثة! أربعة! خمسة!
...
[impatient, whining] انتهينا؟ انتهينا؟
...
[proud] وأنا أسرعُ جملٍ في الواحة!
...
[counting down, excited] ثلاثة… اثنان… واحد… انطلِقوا!
...
[running, proud, out of breath] أقدامي عريضةٌ مثلُ الوسائد، فلا تغوصُ في الرمل! لا أحدَ يلحقُ بي!
...
[sly, excited] هذا الطريقُ أقصر!
...
[squinting against the wind] آه، الرمل! لكنْ لا بأس… رموشي الطويلةُ تحمي عينيّ، وأستطيعُ أن أُغلقَ أنفي!
...
[sad, softly, asking for help] يا أصدقائي… الريحُ غيّرت شكلَ الكثبان. كيف أعرفُ طريقي؟
...
[realizing, happy] والصخرةُ الحمراءُ نحوَ الشمس!
...
[shocked] حَصاة؟! وصلتِ قبلَنا؟!
...
[ashamed, quietly] أنا تسرّعتُ… فضِعت.
...
[cheerful, teaching] هل تعلمون أنّ سنامي لا يخزّنُ الماء؟ بل يخزّنُ الدهنَ ليمنحَني الطاقة!
...
[cheerful] والإحماءُ قبلَ الرياضة…
```

## 2. شاهين، الصوت: **Orus**، والبديل **Algenib**

**Style instructions:**
```
Read in clear Modern Standard Arabic as a confident, smart young falcon cartoon character, a teenage boy. Clear, bright, slightly show-off but kind. Leave a one-second pause between lines.
```

**النص:**
```
[confident] موافق! ومِن فوقُ أرى كلَّ شيء… سأسبقُكما!
...
[proud, amazed] هل تعلمون؟ الشاهينُ أسرعُ طائرٍ في العالم! حين أنقضُّ أتجاوزُ ثلاثَمئةِ كيلومترٍ في الساعة!
...
[calling from far away] رحّال! رأيتُكَ من فوق!
...
[calm, explaining kindly] اسمع… الريحُ تُحرّكُ الرمال، فتتغيّرُ الكثبانُ دائماً، ولا نعتمدُ عليها علامةً للطريق.
...
[warm, wise] لكنّ الشمسَ تُشرقُ من الشرق، وتغربُ في الغرب… وهي لا تخدعُنا.
...
[encouraging] صحيح! هيّا، اتبعني!
...
[cheerful] تعلّمنا اليوم: الشمسُ ترشدُنا…
...
[amazed, whispering] انظروا! ما هذا الذي يلمعُ في السماء؟!
```

## 3. حَصاة (أنثى)، الصوت: **Gacrux**، والبديل **Sulafat**

**Style instructions:**
```
Read in clear Modern Standard Arabic as a gentle, wise old grandmother tortoise cartoon character. Very slow, warm, calm and loving, with soft pauses. Leave a one-second pause between lines.
```

**النص:**
```
[gentle, slow] على مهلِكما يا صغيريّ… قبلَ أيِّ سباقٍ نُحمّي أجسامَنا.
...
[warm, inviting, to the children] وأنتم يا أصدقاء… قوموا معنا!
...
[encouraging, stretching] نمدُّ أيدينا إلى الأعلى… أعلى… أعلى!
...
[rhythmic, counting] نُديرُ أكتافَنا… واحد… اثنان… ثلاثة… أربعة.
...
[slow, calm] والآن نلمسُ أصابعَ أقدامِنا… ببطء.
...
[wise, kind] الإحماءُ يحمي عضلاتِنا من الإصابة. الآن… صِرنا جاهزين.
...
[caring, warning] تذكّروا… الصخرةُ الحمراءُ نحوَ الشمس. لا تبتعدوا عن الطريق.
...
[smiling, calm] مشيتُ ببطء… لكنّي لم أتركِ الطريق.
...
[loving, wise] والأهمُّ أنّنا وصلنا جميعاً. الفوزُ الحقيقيُّ أن نصلَ معاً.
...
[gentle] وبعدَ الرياضةِ… نشربُ الماء.
...
[soft, wise] …ولا نتسرّع.
```

## 4. الراوي، الصوت: **Charon**، والبديل **Iapetus**

**Style instructions:**
```
Read in clear Modern Standard Arabic as a warm, curious storyteller narrating a children's cartoon. Leave a one-second pause between lines.
```

**النص:**
```
[curious, mysterious] كيفَ ضاعَ رحّال؟ لنعُدْ إلى الصباح…
...
[exciting, teaser] الحلقةُ القادمة… سرُّ النجوم.
```

## ملاحظات

- إن قرأ النموذج كلمة `...` بصوت مسموع، فاحذفها واترك سطراً فارغاً بين الجمل.
- شخصية "الجميع" في العدّ تُقرأ بصوت رحّال، وأنا أضيف إليها أصوات الآخرين في المونتاج.
- النسخة المجانية في AI Studio تكفي حلقة كاملة، لكن Google قد تستخدم بياناتها لتحسين نماذجها، وهذا لا يضر نصاً كهذا.
- **علامة "صُنع بالذكاء الاصطناعي":** يوتيوب يطلب الإفصاح عن المحتوى الواقعي المصنوع بالذكاء الاصطناعي. فعّل الخيار عند الرفع حتى في الكرتون، احتياطاً.
