# الجزء 1 | حاتم الطائي والفرس التي طلبها قيصر

حلقة عمودية (9:16) مدتها 98 ثانية بأسلوب الأنمي. الملف الجاهز: `hatim-part1.mp4`. النص من مستند Claude Docs للحلقة.

- `refs/`: صور الشخصيات المرجعية (حاتم، الحاجب، قيصر، ماويّة، الفرس). يُبنى عليها الجزء الثاني.
- `scenes/`: صور المشاهد الـ22.
- `voices/` و`lines.json`: جمل الحوار بأصوات Chatterbox متعدد اللغات.
- `tools/`: سكربتات التوليد:
  - `gen.py`: الصور والتحريك عبر Hugging Face، ويحتاج متغير البيئة `HF_TOKEN`.
  - `tts_local.py`: الأصوات على المعالج.
  - `depth.py` و`parallax.py`: الحركة المجسمة 2.5D.
  - `build.py`: التوقيت والقصاصات والمزج والترجمة.
- `remotion/src/`: المونتاج النهائي.

المشاهد 1 و4 و5 و9 و10 و12 محرّكة بنموذج Wan 2.2، والباقية بحركة عمق 2.5D.
