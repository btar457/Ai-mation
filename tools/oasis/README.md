# أدوات إنتاج فريق الواحة

| الملف | العمل |
|---|---|
| `ep01_lines.py` | سطور الحلقة لكل شخصية، مع الصوت ووصف الأداء |
| `gemini_tts.py` | يولّد كل سطور الشخصية في طلب واحد (`gemini-3.1-flash-tts-preview`) |
| `wan_animate.py` | يحرّك صور المشاهد بنموذج Wan 2.2 على Hugging Face (3.5 ثانية لكل لقطة) |
| `build_episode.py` | المونتاج الكامل: لقطات وحركة كاميرا نحو المتحدث، وترجمة ملونة لكل شخصية، وعنوان، وبطاقة نهاية، وريح، وصوت عند ‎-16 LUFS |

المسارات داخل السكربتات تشير إلى مجلد العمل المؤقت للجلسة، فعدّلها قبل التشغيل. الخطوط المستخدمة: Cairo ExtraBold وLalezar من Google Fonts.
