# Ai-mation 🎨🎬

تطبيق أندرويد (ويعمل أيضاً كتطبيق ويب على أي هاتف) لتوليد الصور والفيديوهات بالذكاء الاصطناعي عبر خدمات **مجانية**.

## المميزات

- **توليد صور** من وصف عربي أو إنجليزي، مع ترجمة تلقائية للإنجليزية لنتائج أفضل.
- **12 نمطاً**: واقعي، سينمائي، أنمي، فانتازيا، ثلاثي الأبعاد، رسم زيتي، ألوان مائية، كوميكس، سايبربانك، بكسل آرت، تراث عربي.
- **مقاسات جاهزة**: 9:16 لتيك توك وريلز، و16:9 ليوتيوب، و1:1، و3:4، و4:3.
- **محركات متعددة**:
  - **Cloudflare FLUX**: من حسابك المجاني في Cloudflare، حصة يومية 10,000 Neuron تتجدد الساعة 3 فجراً بتوقيت بغداد. يدعم كل المقاسات (9:16 و16:9) عبر FLUX.2 klein، والمربع عبر FLUX.1 schnell. يحتاج إعداد Worker مرة واحدة (الخطوات بالأسفل).
  - **FLUX Space** (الافتراضي): مجاني عبر Hugging Face Spaces بحصة GPU يومية. يعمل بدون توكن، والتوكن يعطي حصة أكبر.
  - **AI Horde**: شبكة تطوعية مجانية بلا رصيد ولا مفتاح، وقد تنتظر في الطابور قليلاً.
  - **Pollinations**: بدون مفتاح يسمح بصورة واحدة كل 45 ثانية، وينتظر التطبيق تلقائياً بين الصور. مع مفتاح من enter.pollinations.ai يصبح بدون انتظار (حسب رصيدك).
  - **Hugging Face Inference**: FLUX.1 schnell وFLUX.1 dev وSDXL، وتستهلك الرصيد الشهري المجاني الصغير (تحتاج توكن).
- **تبديل تلقائي**: إذا فشل محرك يجرّب التطبيق المحركات المجانية الأخرى بنفسه.
- **توليد فيديو**: من نص أو من صورة (تحريك الصورة)، عبر نماذج Wan على Hugging Face، أو مجاناً عبر **Google Colab** من زر داخل التطبيق.
- **شخصيات ثابتة**: احفظ وصف الشخصية وSeed ثابت لتحصل على نفس الشكل في كل الصور.
- **معرض** محفوظ على الجهاز، مع الحفظ والمشاركة المباشرة إلى واتساب وتيك توك وغيرها.

## تثبيت التطبيق على الهاتف

### الطريقة 1: ملف APK (أندرويد)

1. مع كل `push` يبني GitHub Actions ملف APK تلقائياً.
2. افتح صفحة **Releases** في المستودع، ثم الإصدار **apk-latest**، وحمّل `Ai-mation.apk`.
3. ثبّت الملف، وفعّل "التثبيت من مصادر غير معروفة" إذا طلب الهاتف ذلك.

### الطريقة 2: تطبيق ويب (أندرويد وآيفون)

ارفع محتوى مجلد `dist` على أي استضافة HTTPS مجانية (GitHub Pages أو Netlify أو Vercel). افتح الرابط من الهاتف، ثم اختر **"إضافة إلى الشاشة الرئيسية"**.

## ☁️ إعداد Cloudflare FLUX (صور مجانية يومياً)

مرة واحدة، من متصفح الهاتف أو الكمبيوتر:

1. ادخل [dash.cloudflare.com](https://dash.cloudflare.com) ← **Workers & Pages** ← **Create** ← **Create Worker**، سمّه `ai-mation` واضغط **Deploy**.
2. اضغط **Edit code**، احذف الكود الموجود، والصق محتوى الملف [`cloudflare/worker.js`](cloudflare/worker.js)، ثم **Deploy**.
3. من صفحة الـ Worker: **Settings** ← **Bindings** ← **Add** ← **Workers AI**، واكتب اسم المتغير `AI` بالضبط.
4. **Settings** ← **Variables and Secrets** ← **Add**، النوع **Secret**، الاسم `APP_KEY`، والقيمة كلمة سرية طويلة من اختيارك. هذه تمنع غيرك من استهلاك حصتك.
5. انسخ رابط الـ Worker (ينتهي بـ `workers.dev`).
6. في التطبيق: **الإعدادات** ← الصق الرابط والكلمة السرية ← **اختبار الـ Worker**. عند النجاح يصبح Cloudflare FLUX المحرك الافتراضي.

> كم صورة يومياً؟ يعتمد على المقاس: المربع عبر FLUX.1 schnell أرخص من الطولي عبر FLUX.2 klein. راقب الاستهلاك من لوحة Cloudflare ← **AI** ← **Workers AI**. عند انتهاء الحصة ينتقل التطبيق تلقائياً للمحركات المجانية الأخرى.

## إعداد توكن Hugging Face (للفيديو والمحركات الإضافية)

1. سجّل في [huggingface.co](https://huggingface.co) مجاناً.
2. اذهب إلى **Settings → Access Tokens → Create new token**.
3. اختر **Fine-grained**، وفعّل صلاحية **Make calls to Inference Providers**.
4. الصق التوكن في تبويب **الإعدادات** داخل التطبيق، واضغط "اختبار التوكن".

> الحساب المجاني على Hugging Face يحصل على رصيد شهري صغير. الصور تستهلك القليل منه، أما الفيديو فيستهلك أكثر بكثير. إذا انتهى الرصيد، استخدم FLUX Space للصور.

## التطوير

```bash
npm install
npm run dev          # تشغيل محلي
npm run build        # بناء نسخة الويب في dist/
```

بناء APK محلياً يحتاج Android Studio وJDK 21:

```bash
npx cap add android
npm run android:sync
cd android && ./gradlew assembleDebug
```
